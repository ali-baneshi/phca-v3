## Claims a minimal version can keep

These are checkable, narrow, and survive the audit:

1. A 12-stage perception/prediction/action loop can run under explicit per-module
   time, memory, energy, and entropy bounds.
2. On a discrete grid, a geometric policy reaches the goal reproducibly for a
   fixed seed. Note that "goal rate" as currently defined is "fraction of cycles
   spent on the goal", which saturates at about 97% on 5×5 because the goal does not
   move. The useful metric is **cycles to first goal** or goals per episode with
   resets.
3. Prediction error decreases over a run on a stationary grid.
4. When a resource bound is violated, the agent takes a neutral action and skips
   consolidation for that cycle.
5. The learned world model's confidence and entropy are exposed and logged even
   when it does not choose the action.

## Claims to drop

- Any statement that the architecture "avoids reward hacking" or is "production
  ready" — neither is measured.
- Any Φ-IQ level ranking.
- Any multi-agent or Observatory capability once the GUI is quarantined.
- Any benchmark number not regenerated by a committed command.
