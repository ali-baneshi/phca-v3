# Phase 1 Cognitive Architecture Research — Knowledge Base

## Purpose

This repository contains a rigorous, first-principles investigation into the foundations of artificial intelligence systems beyond LLM-based architectures. It is designed to serve as a structured knowledge foundation for a future intelligence architecture (Phase 2+).

> **Note:** This tree is **Phase 1 theory only** (no executable code). The running
> PHCA implementation lives in `python/phca/`. See
> [DOCUMENTATION_MAP.md](../DOCUMENTATION_MAP.md) and

## Methodology

This research follows strict rules:
- **No code** — only conceptual + structural analysis
- **Triple verification** — source consistency, logical consistency, contradiction scan
- **Evidence hierarchy** — peer-reviewed papers > established architectures > distributed systems literature > high-quality technical essays
- **Structured markdown** — modular, traceable, reproducible

## Core Objectives

1. Collect and synthesize knowledge from cognitive architectures, neuroscience, distributed systems, complex systems, information theory, control theory, and multi-agent systems
2. Identify hidden assumptions, failure modes, structural constraints, and universal invariants
3. Produce four final deliverables:
   - Intelligence Constraints Model
   - Failure Modes Map
   - Axiom Candidates
   - Architecture Readiness Report
